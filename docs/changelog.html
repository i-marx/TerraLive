Changelog

Terra is built by one person with one rule: everything on screen must be real. This log says what changed and why, including the failures.

September 2026 - the cloud sharpness war, won

The satellite cloud composite sometimes arrives with corrupted tiles. Our repair system was misdiagnosing the cores of real storm systems as corruption and quietly softening them. The detector has been rebuilt around what corruption actually looks like (perfectly flat plateaus, which real clouds never produce), so storm cores now stay razor sharp at full 8K resolution.

September 2026 - the poles get real structure

Geostationary satellites cannot see the poles, so Terra splices in weather-model cover there. That splice used to read as a smooth cap up close; it now carries organic cloud-mass structure while keeping the model's true cover amounts. Aurora rendering doubled in resolution with smooth curtain rays.

September 2026 - light decoupled from spin

The optional slow rotation now orbits the camera instead of spinning the planet against its clock, so the day and night line stays astronomically true while the view drifts.

August 2026 - real moon, real deep sky

The Moon now uses NASA LROC imagery at true scale and phase. Decorative effects were removed rather than polished: if it is not real, it is not in Terra.
